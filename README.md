# Void Runner 🌌

Un juego sencillo de "salta el obstáculo" hecho en HTML, CSS y JavaScript puro — un solo archivo, sin dependencias que instalar.

## Cómo jugar
- **Espacio** o **↑** para saltar (o toca la pantalla en celular)
- Esquiva los bloques ámbar
- Atrapa los orbes menta para puntos extra
- Tu mejor puntaje se guarda automáticamente en el navegador

## Cómo subirlo a GitHub y jugarlo cuando quieras

1. Crea un repositorio nuevo en GitHub (por ejemplo `void-runner`).
2. Sube el archivo `index.html` (y este `README.md` si quieres) al repositorio.
3. Ve a **Settings → Pages** en tu repositorio.
4. En "Branch", selecciona `main` y la carpeta `/ (root)`, luego **Save**.
5. Espera un minuto y GitHub te dará un link tipo:
   `https://tu-usuario.github.io/void-runner/`
6. Guarda ese link (o ponlo de favorito) — ábrelo cuando quieras jugar, desde cualquier dispositivo.

### Alternativa rápida sin Pages
También puedes simplemente descargar `index.html` y abrirlo directamente haciendo doble clic — funciona sin internet ni servidor, en cualquier navegador.

## Personalizarlo
Todo está en un solo archivo `index.html`: los colores están definidos como variables CSS al inicio (`--coral`, `--mint`, `--amber`, `--bg-deep`), y la lógica del juego está comentada en el bloque `<script>`. Cambia esos valores para ajustar el estilo sin tocar el resto del código.
